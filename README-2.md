# Fictioner - A VSCode Extension for Writers

Fictioner is a unique extension for Visual Studio Code, designed by Yunho Jeon (<yunho.jeon@gmail.com>), to transform the popular code editor into a powerful writing environment. Aimed at writers who wish to leverage the efficiency and versatility of VSCode, Fictioner introduces an array of features tailored to the craft of storytelling.

## Features

- **Custom Syntax for Markdown:** Enhances the standard Markdown experience with custom syntax options, making it easier for writers to format and organize their stories.
- **Docx Generation:** Seamlessly convert your Markdown files into `.docx` format, facilitating easy sharing and publishing.
- **Extended Metatag for Chapter Headers:** Use extended metatags to efficiently organize and navigate through chapters.
- **Semantic Checks:** Implement semantic checks with special #tags. Use `#tag?` to raise promises like foreshadowing, `#tag!` to fulfill these promises, and `#tag` to highlight recurring themes. Unmatched tags will raise an error, ensuring narrative consistency.
- **Statistics:** Access detailed statistics about your writing, including word count, readability scores, and more, to help you refine your work.
- **Visual Helper Pane:** A dedicated pane to display related narrative elements (identified by tags) from different chapters, offering real-time assistance as you write.
- **AI-Assisted Features:** Leverage the power of AI for feedback, brainstorming, and text generation, enhancing your writing process with cutting-edge technology.

## Getting Started

To start using Fictioner, follow these simple steps:

1. **Install Fictioner:** Search for "Fictioner" in the VSCode Extensions Marketplace and install it.
2. **Open Your Project:** Load your writing project or start a new one by opening a Markdown file.
3. **Explore Features:** Familiarize yourself with Fictioner's features through the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on macOS) and start enhancing your writing workflow.

## Usage

- **Writing:** Simply begin typing in a Markdown file. Utilize the custom syntax and metatags to structure your narrative.
- **Semantic Checks:** Add `#tags` at the beginning of paragraphs to engage semantic checks and narrative tracking.
- **Generating Docx:** Use the command palette to convert your Markdown files to `.docx` format.
- **Accessing Statistics:** View writing statistics through the command palette or the visual helper pane.
