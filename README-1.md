# Fictioner

Fictioner is a Visual Studio Code extension designed for writers who want to use VS Code as their primary writing tool. It aims to provide an integrated writing environment, similar to an IDE for developers, with features tailored specifically for story writing.

## Features

* **Custom Syntax for Markdown**: Fictioner extends the markdown syntax to better suit the needs of story writers.

* **Docx Generation**: Easily export your markdown files to docx format.

* **Semantic Check**: Fictioner allows writers to add #tags in HTML tags at the beginning of paragraphs. #tag? raises a promise (foreshadow, etc. to be solved). #tag! solves the promise. Unmatched tags raise an error. #tag is used to mark repeating topics.

* **Statistics**: Keep track of your writing progress with built-in statistics.

* **Visual Helper Pane**: This feature shows related parts (identified by tags, from different chapters) to the current part in real-time, helping you maintain consistency and flow in your story.

* **AI Assisted Features**: We're planning to introduce AI-assisted features for feedback, brainstorming, and text generation.

## Extended Metatag for Chapter Header

Fictioner introduces an extended metatag for chapter headers, making it easier to organize and navigate through your story.
